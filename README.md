# 📚 Lucy's Little Library

### An Interactive Watercolor Portfolio & Digital Resume

> *Every book tells a story. Every project is a chapter of mine.*

Welcome to **Lucy's Little Library** — a personal portfolio website designed as an interactive, hand-drawn bookshelf where creativity meets technology.

Instead of navigating through a traditional resume website, visitors are invited to explore a cozy digital library filled with books, illustrations, and personal stories.

Each book represents a different part of my journey, from academic experiences and professional achievements to technical projects and creative explorations.

🌷 **A little library of my experiences, ideas, and everything in between.**

## 📖 Interactive Book Experience

Each book behaves like a physical object.

### 1. Idle State

Books are neatly arranged on the bookshelf.

Subtle shadows and gentle animations create a cozy atmosphere.

### 2. Hover Interaction

When a visitor hovers over a book:

- The book slides slightly forward.
- A subtle rotation creates a natural movement.
- A soft shadow appears.
- The book title becomes more prominent.
- A small handwritten tooltip invites interaction.

### 3. Opening a Book

When a visitor clicks a book:

1. The selected book slides out of the shelf.
2. It moves toward the center of the screen.
3. The book rotates to reveal its front cover.
4. The book expands smoothly.
5. The cover opens with a page-turning animation.
6. The content becomes visible.

The background bookshelf gently blurs to focus attention on the selected book.

### 4. Reading Experience

Visitors can:

- Turn pages
- Explore images and illustrations
- Read project case studies
- Interact with embedded demos
- Open external project links
- Download relevant documents

### 5. Closing a Book

When the visitor closes the book:

1. The pages close.
2. The book returns to its original size.
3. It moves back toward the bookshelf.
4. It slides into its original position.
5. The bookshelf returns to its normal state.

The interaction should feel natural, smooth, and satisfying.

## 🚀 Project Portfolio

Each project is presented as an individual book containing an interactive case study.

### Case Study Structure

Every project follows a consistent storytelling framework:

1. **Cover** — Project title, category, and illustration
2. **Overview** — Introduction and objectives
3. **Problem** — Challenges and user needs
4. **Process** — Research, planning, and design decisions
5. **Solution** — Implementation and key features
6. **Outcome** — Results, reflections, and lessons learned

Where appropriate, project books can include:

- Interactive prototypes
- Embedded dashboards
- UI/UX mockups
- Screenshots
- Product demonstrations
- GitHub repositories
- Live demo links

The objective is to showcase both the final results and the thinking behind each project.

## ✨ Animation & Interaction

The website prioritizes smooth, organic, and purposeful motion.

### Core Animations

- Scroll-triggered content reveals
- Smooth book extraction
- Book opening and closing transitions
- Page-turning animations
- Gentle floating illustrations
- Hand-drawn SVG path animations
- Subtle parallax effects
- Animated tooltips
- Responsive hover effects
- Interactive character animations

### Animation Principles

Animations should:

- Feel natural rather than mechanical
- Support navigation and storytelling
- Maintain consistent timing
- Avoid unnecessary visual distractions
- Remain performant on mobile devices
- Respect reduced-motion accessibility preferences

The goal is to create a delightful browsing experience without sacrificing usability.

## 💻 Getting Started

### Prerequisites

- Node.js
- pnpm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/personal-portfolio.git
```

Navigate into the project:

```bash
cd personal-portfolio
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open:

```text
http://localhost:3000
```

The development server will display the website locally.

*Note: These instructions apply after the Next.js project has been initialized and its dependencies have been configured.*

## 🎯 Design & Development Principles

### 1. Storytelling First

Every interaction should contribute to the experience of exploring a personal digital library.

### 2. Creativity Meets Professionalism

The visual design should feel artistic and playful while keeping professional information clear and accessible.

### 3. Performance Matters

Animations should be smooth, lightweight, and optimized for real-world devices.

### 4. Accessibility

The website should support keyboard navigation, semantic HTML, readable contrast, and reduced-motion preferences.

### 5. Responsive by Design

Every feature should work across desktop and mobile devices.

### 6. Maintainability

Components should be reusable, content-driven, and easy to extend as new projects are added.

### 7. Authenticity

All experiences, achievements, and project outcomes should accurately represent my work.
